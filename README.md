# Chrysocolla Conduit

Full-colour Python 3 neon pipe-flow arcade for ElbowOS.

Rotate copper ducts so chrysocolla coolant reaches the gem chambers. A missed joint stops the flow. Open all four chambers.

Arrows move the cursor. Space rotates a duct. R restarts.

## Play

```bash
pip install -r requirements.txt
python3 chrysocolla_conduit.py --play
```

## Record a 9:16 reel

```bash
python3 chrysocolla_conduit.py --record
```

Writes a 1080x1920, 15 second, 30 fps H.264 MP4.
